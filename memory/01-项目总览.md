# 01 项目总览

## 当前有效摘要

`harness-Dev-TC` 是用于在 Codex / ChatGPT 环境中恢复 AI 产品交付协作规则的 Git 仓库。当前可恢复基础规则、项目入口、核心 Skill 与迁移手册；不能仅凭本仓库恢复原项目的真实业务上下文。

## 产品定位

为产品调研、方案、交互/UI、技术设计、开发、测试、部署、上线和复盘提供统一的任务分级、上下文读取、授权控制、Memory 路由与质量门禁。

## 当前目标

- 通过 Git 克隆恢复自包含基础规则。
- 保持外部写入、插件连接、账号授权和高风险动作的用户控制权。
- 对缺失证据、未验证能力和未恢复上下文进行显式标记。
- 按阶段完成迁移与验收，不把文件存在等同于 Harness 已生效。

## 目标用户与场景

- 目标用户：在 Codex / ChatGPT 中开展 AI 产品工作的产品经理或项目协作者。
- 核心场景：跨设备恢复、长期项目接续、复杂任务执行、设计与工程交付验收。

## 当前边界

本仓库不包含：

- 原项目完整 `memory/00` 至 `09` 内容；
- 原项目附件、截图、代码和完整历史；
- API Key、Token、Cookie、登录态、环境变量或设备证书；
- 插件缓存、会话缓存和第三方 Hooks 配置；
- 尚未获得真实资料支持的业务结论与正式决策。

## 权威资料入口

- 基础执行规则：`../AGENTS.md`
- 迁移规范：`../Harness-跨设备迁移与重建手册-V1.0.md`
- 当前恢复状态：`02-当前上下文.md`
- 正式决策：`03-历史决策.md`

## 稳定层待确认

- 原项目完整文件夹是否仍可提供。
- 是否将本仓库仅作为通用 Harness 模板，还是继续恢复某个具体业务项目。
- 真实业务资料提供后，`04` 至 `09` 的建立顺序和范围。
